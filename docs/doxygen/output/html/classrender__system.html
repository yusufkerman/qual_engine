◆ render()

void render_system::render ( const registry & reg,
const light_batch & lightBatch,
struct EngineContext & ctx,
const glm::mat4 & view,
const glm::mat4 & projection )

Sahneyi ana ekrana ve gölge haritalarına render eder.

Pipeline akışı:

  1. Işık verisinin UBO aracılığıyla GPU'ya iletilmesi.
  2. ECS'den render edilebilir nesnelerin çıkarılması (Extraction & Culling).
  3. Shader bazlı çizim gruplaması (Batching).
  4. Gölge geçişi (Shadow Pass) ve ana çizim geçişi (Main Pass).
Parametreler
regSahnedeki varlık kayıt defteri.
lightBatchGPU'ya aktarılacak paketlenmiş ışık verileri.
ctxMotor bağlamı (FBO, Renderer ve Aria varlık sistemlerine erişim).
viewKameranın görünüm (View) matrisi.
projectionKameranın iz düşüm (Projection) matrisi.
